# Доменные сущности

| Наименование сущности     | Описание                                                                                                                                   | Связи с другими сущностями                                                                                                               |
| ------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------- |
| **Единица измерения**     | Определяет единицу, в которой измеряется количество продукции, сырья или других учитываемых объектов. Низкий порядок.                      | Используется в `Ингредиент`, `Номенклатура`, `Технологическая карта` и других сущностях, где требуется указание количества.              |
| **Деньги**                | Представляет денежную сумму, используемую для учета стоимости и проведения расчетов. Низкий порядок.                                       | Используется в `Блюдо`, `Заказ`, `Контракт` и других сущностях, связанных с финансовыми показателями.                                    |
| **Ингредиент**            | Представляет продукт или сырье, используемое при приготовлении блюд и полуфабрикатов. Низкий порядок.                                      | Связан с `Единица измерения`, входит в состав `Блюдо` и `Технологическая карта`, учитывается на `Склад`.                                 |
| **Номенклатура**          | Представляет объект складского и производственного учета: сырье, продукцию, полуфабрикаты и другие материальные позиции. Низкий порядок.   | Относится к `Группа`, связана с `Единица измерения`, учитывается на `Склад` и используется в `Технологическая карта`.                    |
| **Адрес**                 | Представляет сведения о местоположении объекта или точки доставки. Низкий порядок.                                                         | Используется в `Ресторан` и `Заказ`, а также при организации доставки.                                                                   |
| **Сотрудник**             | Представляет работника организации. Низкий порядок.                                                                                        | Связан с `Ресторан`, `График работы`, `Контракт`, а также с учетными операциями, выполняемыми сотрудником.                               |
| **Контрагент**            | Представляет сторону, с которой организация осуществляет хозяйственные или финансовые взаимодействия. Низкий порядок.                      | Относится к `Группа`, используется в `Контракт` и финансовом учете.                                                                      |
| **Группа**                | Используется для классификации и объединения однотипных объектов. Низкий порядок.                                                          | Может быть связана с другой `Группа` и использоваться для объединения `Номенклатура`, `Контрагент` и других объектов.                    |
| **Тип оплаты**            | Определяет способ проведения оплаты: наличные, банковский перевод и другие варианты. Низкий порядок.                                       | Используется в `Заказ` и финансовых операциях.                                                                                           |
| **Блюдо**                 | Представляет готовую продукцию ресторана, состоящую из определенного набора компонентов. Высокий порядок.                                  | Связано с `Ингредиент`, `Номенклатура`, `Технологическая карта`, `Деньги` и используется в `Заказ`.                                      |
| **Технологическая карта** | Описывает состав продукции и порядок ее приготовления. Высокий порядок.                                                                    | Содержит `Ингредиент` и `Номенклатура`, использует `Единица измерения`, связана с `Блюдо` и может включать другие технологические карты. |
| **Склад**                 | Представляет место хранения сырья, полуфабрикатов и готовой продукции с учетом их остатков. Высокий порядок.                               | Связан с `Ресторан`, `Номенклатура`, `Ингредиент` и операциями складского учета.                                                         |
| **Ресторан**              | Представляет отдельную точку ресторанной сети, участвующую в хранении продукции, приготовлении блюд и выполнении заказов. Высокий порядок. | Связан с `Адрес`, `Склад`, `Сотрудник`, `Блюдо` и `Заказ`.                                                                               |
| **Контракт**              | Представляет договорные отношения организации и содержит основные сведения об участниках и условиях договора. Высокий порядок.             | Связан с `Контрагент`, `Сотрудник` и `Деньги`.                                                                                           |
| **График работы**         | Определяет рабочие смены и время работы сотрудников. Высокий порядок.                                                                      | Связан с `Сотрудник` и используется для учета его рабочего времени.                                                                      |
| **Заказ**                 | Представляет заказ и процесс его выполнения от поступления до выдачи или доставки. Высокий порядок.                                        | Связан с `Ресторан`, `Блюдо`, `Склад`, `Адрес`, `Деньги` и используемой `Номенклатура`.                                                  |
| **Инвентаризация**        | Представляет проверку фактического наличия номенклатуры на складе. Может быть полной или частичной. Высокий порядок.                       | Связана со `Склад`, `Номенклатура`, `Группа` и `Сотрудник`.                                                                              |
