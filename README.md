# Patterns2026

Проект автоматизации процессов сети ресторанов «Ромашка».

Система охватывает складской и производственный учет, работу с заказами, финансовый учет, учет персонала и оперативные процессы.

## Документация

- [Техническое задание](Docs/TechnicalTask.md) — требования к системе и предметной области.
- [Доменные сущности](Docs/Entities.md) — основные сущности системы и связи между ними.
- [Соглашение по оформлению кода](Docs/CodeCases.md) — правила именования, структуры и оформления исходного кода.

## Структура проекта

- `Src/Core` — общие классы, константы и перечисления.
- `Src/Logics` — классы, реализующие бизнес-логику.
- `Src/Models` — доменные модели.
- `Src/Dtos` — DTO для передачи данных.
- `Tst` — модульные, интеграционные и функциональные тесты.
- `Docs` — документация проекта.

## Запуск REST API

```bash
pip install -r requirements.txt
python main.py
```

Документация и проверка запросов доступны в Swagger UI:
`http://127.0.0.1:8000/docs`.

- `/api/reports/{response_format}/{value_type}/{code}` — отчёт в явно
  указанном формате.
- `/api/reports/{value_type}/{code}` — отчёт в формате из настроек.
